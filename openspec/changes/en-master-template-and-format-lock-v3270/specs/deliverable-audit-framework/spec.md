# Specification: EN Master Template & Formatting Immutability

## Requirements
- The English MSDS template MUST strictly adhere to the 12-row Table 7 geometry.
- The pipeline MUST NOT alter any existing bold run, font size, cell margins, or table borders from the master template.
- Dynamic values MUST be written into value cells inheriting non-bold font style.
- Output English PDFs MUST contain 0 Chinese characters and render cleanly in exactly 7 pages.
