# MSDS/TDS 独立开行与分段判定准则 (Independent Row & Paragraph Playbook)

本准则用于规范化解决 MSDS 与 TDS 表格和正文编写中“内容挤在同一单元格或同一行”的排版与语义缺陷，确立严格的独立开行（Independent Table Row）与独立分段（Independent Paragraph）工程化判定标准。

---

## 一、核心原则：三大独立开行定律

### 1. 实体层级不同，必须独立开行（主客体分行律）
在毒理学（Section 11）、生态学（Section 12）以及理化信息中，不同层级的评估实体绝对不可混合挤入同一行：
- **整机/混合物层级（Product-level Overall Evaluation）**：如 `该产品无可用的毒理学研究。` 作为产品整体现状，必须占据独立的表格行（Row 1）。
- **聚合物/主体分散体层级（Polymer / Matrix Evaluation）**：如 `羟基聚丙烯酸酯分散体：毒性：无资料；刺激性：无资料。` 作为特定聚合物基质，必须单独开辟新行（Row 2），严禁与整机说明合并在同一行。
- **组分引用前言（Component Reference Preamble）**：如 `以下为组分（二丙二醇丁醚，CAS 29911-28-2）的毒理学参考数据：`，作为引导具体化学组分数据的过渡语句，必须独立成行（Row 3）。
- **组分实测数据（Component Experimental Endpoints）**：各测试终点（急性毒性、皮肤刺激、眼睛刺激）依序独立成行。

> **判定口诀**：整机一行、聚合物一行、组分引言一行、各测试指标各一行。绝不越级并列。

---

### 2. 法规与逻辑类别不同，必须独立开行/分段（分类边界律）
在危险性概述（Section 2）、成分信息（Section 3）以及应急防范措施中，不同法定性质的说明必须有明确的物理边界：
- **GHS 分类结论 与 关切物质特别提示**：
  - 分类结论：`羟基丙烯酸酯聚合物GHS危险性分类：不适用`（独立行/段）
  - 关切物质提示：`请注意以下物质：`（独立行/段）
  - 物质明细与特定限值：`N,N-二甲基乙醇胺，中和剂，已键合为盐，质量浓度小于2.0%`（独立行/段）
- **防范说明的四大逻辑阶段**：
  - 预防措施（Prevention）、事故响应（Response）、安全储存（Storage）、废弃处置（Disposal）四大块必须具有明确的前缀标题（如 `预防措施：`、`事故响应：`）并分行排列，每个具体的 P 码及其实质性防护说明单独成行，严禁串成一行大长句。

---

### 3. 数据指标与测试方法，必须一指标一行（结构化对照律）
在 TDS 技术指标表（Table 0）以及 MSDS 理化性质表（Table 8 / Section 9）中：
- 每个技术指标（外观、固含量、羟基含量、粘度、pH值、密度）严格占据表格的一行，具有独立的指标名、数值范围、单位和测试方法列。
- 若源文件中出现理论计算值或补充指标（如羟基含量 3.3%），必须克隆行并在表格骨架中插入独立新行，严禁将两个指标的数值拼在一个单元格内。

---

## 二、代码实现规范（禁止软换行与单元格混挤）

1. **表格结构优先原则**：
   当需要在已有表格模板中增加层级说明时，必须通过 `deepcopy(row._tr)` 动态插入新行 `tr`，而不得在既有单元格内用 `\n` 硬塞多层级信息。
2. **段落级属性继承原则**：
   在必须承载多行文本的单元格（如防范说明、标签要素）内部，必须调用 `set_cell_value_unified` 分割为独立的 `<w:p>` 元素，每个段落独立继承 `<w:rPr>` 属性，禁止通过单一 Run 包含回车字符 `\n` 充当伪换行。
