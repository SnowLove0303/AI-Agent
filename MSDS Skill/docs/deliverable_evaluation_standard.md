# MSDS 产出物评判标准 v1.0

这是一套内部发布门，用来判断一个 MSDS 八文件交付包是否可以交给客户。它不是法规合规意见，也不能替代责任人的最终审核；但任何 B0/B1 问题都必须在交付前关闭。

## 1. 适用对象

一次完整交付默认包含同一产品的：

1. 中文冠志 DOCX/PDF
2. 中文国彩 DOCX/PDF
3. 英文冠志 DOCX/PDF
4. 英文国彩 DOCX/PDF

DOCX 是内容和版式主文件；PDF 只能从对应的最终 DOCX 转换得到。

## 2. 一百分模型

| 维度 | 分值 | 评判重点 |
|---|---:|---|
| 源事实与语义 | 30 | 源文件身份、内容保真、正确归类、示例事实隔离、Section 2/3/9/11 |
| 模板结构与受控覆写 | 25 | 模板 lineage、geometry、白名单、锁定序号/标签列、Section 8/14 |
| DOCX 版式与视觉质量 | 20 | 页面、表格、换行、图片、溢出、关键章节逐页可读 |
| 四格式语义与公司一致性 | 10 | CN/EN 语义等价、冠志/国彩只改变获准公司字段 |
| DOCX 派生 PDF 与 PDF 质量 | 10 | 一一派生、页数/尺寸/文字/图片、逐页 QA |
| 发布包与证据完整性 | 5 | 八文件、manifest、ZIP 清洁度、V2.9 inheritance、证据闭环 |
| **合计** | **100** | |

单条规则按其登记分值计入；PASS/OBSERVED 得满分，FAIL/NOT_CHECKED/ERROR 得 0 分。B2 观察项不阻断，但默认不计分，除非规则本身明确允许观察状态。

## 3. 结果等级

| outcome | 条件 | 客户交付 |
|---|---|---|
| `RELEASE_PASS` | 无 B0/B1；所有必需规则均已执行；证据完整；分数 ≥95 | 可以进入客户交付流程 |
| `RELEASE_FAIL` | 存在 B0/B1，或明确发现内容/模板/PDF 硬错误 | 不得交付，先修复再审计 |
| `NOT_READY` | 没有硬阻断，但分数不足、输入不全或存在未检查/错误项 | 不得当作通过，补齐后重跑 |
| `OBSERVATION_ONLY` | 显式要求只查看现状 | 仅供诊断，不代表发布结论 |

分数永远不能覆盖 B0/B1。尤其是模板骨架改变、示例产品事实泄漏、PDF 无法追溯到最终 DOCX、八文件缺失或关键视觉错误，即使分数很高也必须 `RELEASE_FAIL`。

## 4. 客户视角最低标准

- 客户看到的是产品事实，不会看到源文件请求、草稿说明或审计内部话术。
- 每个 Section 的标签、序号、换行和版式与批准模板一致。
- Section 3 一个成分一行；无数据只写约定表达，不写“无数据资料”。
- Section 11 有源数据就必须正确归类并保留；不得把存在的数据写成“无数据”，不得追加未要求的推断。
- 英文版沿用 EN 模板原位覆写，不重建表格，不以排版方便改变锁定骨架。
- 客户拿到的四个 PDF 与四个 DOCX 一一对应，且 PDF 不需要人工补救。

## 5. 必须验证的边界案例

评分器和回归测试必须覆盖：95 分边界、94.99 分、观察模式、高分伴随 B0/B1、缺失规则、`NOT_CHECKED`、`ERROR`、Section 9 全部缺失项、Section 11 眼睛刺激性别名归类、Section 3 多成分、PDF 配对错误以及 ZIP 重复文件。
