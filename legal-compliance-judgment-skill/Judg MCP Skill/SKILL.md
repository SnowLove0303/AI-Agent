# 化学物质法律法规合规性判断技能 (Substance Regulatory Compliance Query)

本技能指导 Agent 通过 `substance-compliance-mcp` 服务提供的标准 MCP 工具，高效、准确地查询化学物质及多组分配方在主流化学品监管法规中的合规状态，并生成严谨权威的合规判断结论与结构化审查矩阵。

---

## 1. 核心监管法规库范围

本服务底层联动六大官方/行业严苛化学品限制法规库：

| 法规代码 | 全称与官方依据 | 核心基线 / 判定基准 |
| :--- | :--- | :--- |
| **EU_ROHS** | 欧盟 RoHS 2.0 (2011/65/EU & (EU) 2015/863) | 均质材料限值：镉 (Cd) 100 ppm (0.01%)；铅/汞/六价铬/PBB/PBDE/4项邻苯 1000 ppm (0.1%) |
| **REACH_SVHC** | 欧盟 REACH 高度关注物质候选清单 (SVHC 253项) | 物品或配方中含有 >0.1% (w/w) (1000 ppm) 即强制触发供应链信息传递与 ECHA SCIP 通报义务 |
| **REACH_ANNEX_XVII** | 欧盟 REACH 附录 XVII 限制物质清单 (86大类条目) | 制造、投放市场或特定消费/工业用途的强制性条件限制或全面禁用 |
| **BSBL** | BSBL 限制物质清单 (BSBL v8.0) | 鞋服、纺织、高分子涂层与鞋材制造严苛限制标准（51分类，按材料分类设定严格限量） |
| **HSF_001** | 企业 HSF-001 有害物质控制标准 | 企业绿色产品材料准入标准与供应链限制规范 |
| **AFPS_PAK** | 德国 GS 认证 AfPS GS 2019:01 PAK 限制清单 | 消费品、玩具及与人体接触材料中 15 项多环芳烃分级限量要求 (0.2 ~ 50 mg/kg) |

---

## 2. MCP 工具调用规范

在响应用户查询时，必须优先调用 `substance-compliance-mcp` 提供的工具获取确切法规数据，严禁仅凭模型记忆猜测法规限值或条目状态。

### 工具 1：`check_substance_compliance`（单物质合规筛查）
用于单个物质的合规性核实，支持浓度超标计算与特定法规过滤。

- **调用参数**：
  - `substance`: 必填。CAS 号（如 `"7439-92-1"`）、EC 号（如 `"231-100-4"`）或中英文名称（如 `"铅"`、`"双酚A"`、`"Lead"`、`"BPA"`、`"DEHP"`）。
  - `concentration_pct`: 可选。实测质量百分比浓度（单位 `% w/w`，如 `0.05` 代表 0.05%）。
  - `concentration_ppm`: 可选。实测质量百万分比浓度（单位 `ppm` 或 `mg/kg`，如 `500` 代表 500 ppm）。
  - `regulations`: 可选。若用户仅关心某些法规，可传入代码列表，如 `["EU_ROHS", "REACH_SVHC"]`。默认检查全部 6 项法规。
  - `material_type`: 可选。均质材料分类，如 `"塑料"`, `"金属"`, `"皮革"`。

### 工具 2：`batch_check_compliance`（多组分/配方批量筛查）
用于 MSDS 第 3 部分、TDS 成分表或原料配方清单的整体合规评价。

- **调用参数**：
  - `components`: 组分对象列表。例：
    ```json
    [
      {"substance": "7439-92-1", "name": "铅", "concentration_ppm": 500},
      {"substance": "双酚A", "concentration_pct": 0.05},
      {"substance": "64-17-5", "name": "无水乙醇", "concentration_pct": 80.0}
    ]
    ```
  - `regulations`: 可选法规范围过滤。

### 工具 3：`search_regulatory_substances`（法规清单模糊检索）
用于用户不确定 CAS 号或需要了解某类物质在受限清单中的收录情况。

- **调用参数**：
  - `keyword`: 检索关键词（如 `"邻苯"`, `"tin"`, `"117-"`, `"阻燃剂"`）。
  - `regulation`: 可选。指定在 `"REACH_SVHC"`, `"EU_ROHS"`, `"BSBL"` 等清单内检索。
  - `limit`: 最大返回条数（默认 20 条）。

### 工具 4：`get_regulation_info`（法规标准与限值依据查询）
用于向用户解释某一法规的具体背景、版本基线、受控范围及限量准则。

- **调用参数**：
  - `regulation`: 法规标识代码（如 `"EU_ROHS"`, `"REACH_SVHC"`, `"AFPS_PAK"`）。

## 3. 专业答复输出结构规范

调用 MCP 工具后，Agent 应以专业合规工程师的口吻，将返回的 JSON 数据组织为层次清晰、依据确凿的 Markdown 交付报告：

**综合合规判定**: 【[合规 / 未受限] 或 [受法规限制 / 需满足限制条件] 或 [不合规 / 存在超标违规]】

#### 1. 物质标识解析
- **中文名称**: [中文官方名称]
- **英文名称**: [英文官方名称]
- **CAS 登记号**: [标准CAS格式]
- **EC / EINECS 号**: [EC号，若有]
- **审查浓度基准**: [实测浓度 或 "未提供浓度（仅做列入性与定性限制筛查）"]

#### 2. 六大法规合规性比对矩阵
| 监管法规 | 收录状态 | 核心限值 / 阈值 | 实测浓度判定 | 详细管控要求与条款 |
| :--- | :---: | :---: | :---: | :--- |

## 4. 极端与边界情况处理准则

1. **多重 CAS 号与异构体**：若某化合物存在多种同分异构体或 CAS 集合（如多溴联苯、得克隆），工具会自动按代表性 CAS 或关联群组解析，并在报告中予以说明。
2. **浓度单位自动换算**：`1% (w/w) = 10,000 ppm = 10,000 mg/kg`。无论用户提供 `%` 还是 `ppm`，工具均能自动双向对齐比对。
3. **未收录物质**：若某物质在六大清单均未检出（如无水乙醇 `64-17-5`），明确给出 `COMPLIANT_NOT_LISTED` 结论，表明其未受到上述六项专项限制，但仍需遵守常规化学品安全规范。
