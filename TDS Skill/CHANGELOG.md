# Changelog

## 1.3.7 — 2026-09-07

- 英文 TDS 输出统一使用专业章节标题，优化 `waterborne polyurethane dispersion`、产品特性、应用、储存及性能指标术语和句式；统一 `forced-air oven`、`MPa`、`mPa·s`、范围符号等技术写法。
- 英文源文档提取兼容 `Product Description`、`Product Features` 等标准化标题。

## 1.3.6 — 2026-09-07

- 修复产品特性自动编号的列表布局：编号与正文基准线统一，正文采用紧凑悬挂式缩进，编号后不再使用远距离制表位。
- 清除产品特性区域空段的 `numPr`、tab 和缩进属性；新增特性插入到原有分隔段之前，审计禁止条目之间出现额外空编号段。

## 1.3.5 — 2026-09-07

- 按更新后的四套模板动态注册【Product features】产品特性槽位与分隔段，不再硬编码旧段落位置。
- 保留模板自动编号；扩展特性按模板的特性段落和分隔段成对插入，统一行间距并由审计校验编号、间距和结构契约。

## 1.3.4 — 2026-09-04

- 恢复特性条目模板自动编号（覆写时加 `numPr{ilvl0,numId1}`，与 1.3.0 模板编号定义一致；源手工序号照旧剥离，序号永不重复）；扩展条目自动续号。
- 扩展条目改为分隔空行+条目成对插入，保持模板 `[条,空,条,空]` 节奏；审计中间区分区比对（忽略编号差异）+ 特性编号一致性检查。

## 1.3.3 — 2026-09-04

- 源无对应说明的章节经 Agent 批准后整节隐藏（标题+内容删除，不写无数据）；`product.title` 永不隐藏，缺失直接阻断。
- 审计跳过隐藏字段的双语必填检查，按删除后几何校验，锚点标题动态回退；空章节进入 ledger 为 `hide_no_source_candidate` 待 Agent 确认。

## 1.3.2 — 2026-09-04

- 内化用户最新提供的四个 TDS `.doc` 模板；来源文件原样保留，active DOCX、注册表和结构快照更新为新基线。
- 按用户取消智能编号的意图，清除 active 特性槽位的残留段落编号；覆写时继续清除源文本的显示性手工序号，避免重复编号。
- 快照与审计增加段落/字符间距及特性编号状态，注册阶段强制两个特性槽位等间距且不带 `numPr`。

## 1.3.1 — 2026-09-04

- 内化用户提供的四个新 TDS `.doc` 模板并刷新四个 active DOCX、来源 hash、active hash、结构 snapshot 和 package baseline。
- 更新 EN registry：性能表锁定标签按英文模板校验，并吸收新的英文列宽与标签结构；CN 基线同步登记新来源 hash。
- 增加模板变更回归覆盖，确保新 EN grid widths、英文性能标签和四变体 fresh-clone 覆写链路保持一致。

## 1.3.0 — 2026-09-04

- 明确 TDS 主链路为“原始证据抽取 → 事实整理/语义标准化 → 专业英文翻译 → 模板原位覆写”，不再把源值和最终覆写值视为同一层。
- 为标准化模型增加 `source_values`、`normalized_values`、provenance 和 decision ledger；性能行保留原始值与标准化输出值两套证据。
- 增加 Agent 判断协议：强标注框架和白名单是硬约束，别名、模板示例和历史案例只是线索；歧义未解决时 fail closed。
- 英文覆写明确以标准化模型为唯一输出来源；英文源文件只作为目标语言证据/校验材料。
- CLI 增加 `--normalized-mapping`，支持 Agent 审批后复用同一标准化 mapping 构建，避免重复抽取和重复排版。

## 1.2.0 — 2026-09-04

- 将性能表覆写改为源文件主导：严格保留源行顺序、项目名称、限定条件、指标值、单位和测试方法；裁剪未使用的模板示例数据行，超出容量时才克隆行。
- 禁止不同检测条件的语义归类，新增源文件—输出文件逐行 parity 审计和明确的发布阻断。
- 将真实 PU-1001/PU-1002 回放纳入验证，避免仅验证模板外观而遗漏源事实错误。

## 1.1.1 — 2026-09-04

- 扩充常见中文性能指标别名识别，避免真实源文件的“外观”“固体份含量”“粘度(25℃)”等写法被误判为扩展行。
- 抽取时不再把“性能指标”标题写入供应形式；产品特性源文自带编号时按模板自动编号输出，避免重复编号。
- 性能表改为源文件驱动，保留源行顺序、原始项目标签和限定条件，不再插入模板独有的示例指标。

## 1.1.0 — 2026-09-04

- 增加性能指标行和产品特性段落的受控延展：只克隆维护模板样式，既有骨架不移动。
- 未知性能指标按各语言源文件的出现顺序配对；源表超过四列、数量不一致或容量超限时 fail closed。

## 1.0.0 — 2026-09-04

- 新增独立 TDS Skill，与 MSDS Skill 分目录、分映射、分程序和分测试。
- 内化四个用户维护模板：CN/EN × 冠志/国彩；建立来源 hash、active DOCX、registry 和 geometry/package snapshot。
- 建立一次抽取、统一 semantic model、四变体一一映射、fresh-clone 原位覆写和 fail-closed 约束。
- 建立四 DOCX + 四 DOCX-derived PDF 的八格式构建和发布审计入口。
